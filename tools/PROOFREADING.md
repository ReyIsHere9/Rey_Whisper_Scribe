# Local LLM proofreading experiments (WIP)

Status: experimental. Not integrated into the application.

## Why this is WIP

Two prompt-only approaches were tested locally with Ollama and Qwen2.5 7B:

1. **Full-text proofreading** undercorrected. It preserved valid-looking but wrong words.
2. **Numbered edit-list proofreading** produced more edits but still missed non-word/homophone/verb errors and sometimes invented bad replacements.

Prompt engineering alone is not reliable enough. The next step is a hybrid pipeline:

```
ASR text
  -> Persian normalizer
  -> token/morphology checks
  -> lexicon + spell candidate generation
  -> date/number checks
  -> LLM selects KEEP or one real candidate
  -> edit applier with provenance
  -> review UI
```

The LLM must never invent a replacement; it chooses from candidates generated by the deterministic layer.

## Scripts

- `bench_ollama.py` — compares model speed and output on a sample.
- `proofread_ollama.py` — v1 full-text chunked proofreading.
- `proofread_ollama_edits.py` — v2 numbered edit-list proofreading.

Samples and outputs belong in `models/bench/`, which is git-ignored.

## Requirements

- Ollama installed and running locally.
- `qwen2.5:7b` pulled (3B was not reliable for this task).
- No Ollama account or API key is required; the API is local at `http://localhost:11434`.

## Commands

```powershell
# Speed/quality benchmark
.venv\Scripts\python.exe tools\bench_ollama.py

# Full-text proofreading (v1)
.venv\Scripts\python.exe tools\proofread_ollama.py `
  --input path\to\input.txt `
  --output models\bench\out.txt `
  --diff models\bench\diff.txt

# Edit-list proofreading (v2)
.venv\Scripts\python.exe tools\proofread_ollama_edits.py `
  --input path\to\input.txt `
  --output models\bench\out-v2.txt `
  --diff models\bench\diff-v2.txt
```

## Known limitations

- 7B does not reliably know Persian word validity or verb morphology.
- No Persian lexicon, spell checker, morphology analyzer, or domain glossary yet.
- No word-level confidence/highlight/review UI yet.
- No app integration yet.
